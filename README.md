# 📦 Packing Recorder
### 주문번호 기반 포장 영상 기록용 Windows 데스크톱 애플리케이션

포장 작업을 카메라로 녹화하고, 주문번호와 작업 날짜를 기준으로 영상을 로컬 저장소에 관리하는 프로그램입니다.

**저장 위치 선택 → 날짜 폴더 준비 → 주문번호 입력 → 녹화 → 영상 저장**

Electron 기반의 독립 실행형 Windows 앱으로, 별도 서버·데이터베이스·로그인 없이 사용할 수 있습니다.

## 1️⃣ 프로젝트 소개

> “포장 과정을 주문번호와 함께 기록하고, 필요한 영상을 로컬에서 확인한다.”

저장 위치로 PC 내부 폴더 또는 이동식 저장소를 선택할 수 있으며, 선택한 날짜의 폴더에 주문번호가 포함된 영상 파일을 저장합니다.

### 🚀 주요 특징

- 주문번호 기반 영상 파일 관리
- 작업 날짜별 저장 폴더 생성 및 재사용
- 카메라 선택과 실시간 미리보기
- 녹화·일시정지·재개·정지
- 실제 Windows 소형 창 전환 및 항상 위 표시
- WebM 영상의 길이·탐색 정보 후처리
- 외부 서버 없이 로컬에서 녹화 및 저장

---

## 2️⃣ 사용 시나리오

1. 저장 폴더와 작업 날짜를 선택
2. 시작 버튼을 눌러 카메라를 연결
3. 주문번호를 입력하고 녹화
4. 정지 버튼을 눌러 영상을 저장
5. 저장 폴더에서 결과 영상 확인

## 5️⃣ 프로젝트 구조

앱 소스는 배포 폴더의 `resources/app/`에 있습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 및 스타일 |
| `renderer.js` | 카메라 연결, 녹화 제어, 화면 상태 관리 |
| `main.js` | 앱 실행, Windows 창, 폴더 선택, IPC |
| `preload.js` | Renderer와 Main 사이의 제한된 API |
| `storage.js` | 날짜 폴더 및 영상 파일 관리 |
| `finalize-webm.js` | FFmpeg 실행 및 WebM 후처리 |
| `package.json` | 프로젝트 정보, 의존성, 실행 명령 |

### 배포 파일 구성

| 경로 | 내용 |
|---|---|
| `PackageRecorder.exe` | Windows 실행 파일 |
| `resources/app/` | 애플리케이션 소스 |
| `resources/tools/ffmpeg.exe` | 영상 후처리 실행 파일 |
| `locales/` 및 DLL 파일 | Electron 실행에 필요한 구성 파일 |
| `README.md` | 프로젝트 설명 |

### 영상 저장 경로

```text
선택한 저장소/YYYY-MM-DD/주문번호_시간_고유값.webm
```

## 6️⃣ 실행

1. ZIP 전체를 압축 해제합니다.
2. `PackageRecorder.exe`를 실행합니다.
