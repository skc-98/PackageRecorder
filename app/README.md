# Packing Recorder — Windows 앱 v1.0.1

## 실행 (사용자)

ZIP 전체를 원하는 폴더에 압축 해제하고 **PackageRecorder.exe**를 더블 클릭하세요.
Python, Node.js, Chrome 설치, 터미널 명령, 서버 실행, 로그인은 필요 없습니다.
Windows 10/11 x64용 포터블 앱입니다. 설치 프로그램은 아닙니다.
EXE 옆의 DLL, resources, locales 등의 파일도 필요하므로 EXE만 따로 옮기지 마세요. 바탕화면에는 EXE의 바로가기를 만들면 됩니다.

이 앱에 별도 코드 서명 인증서를 적용하지 않았습니다. Windows의 표시 이름/제작자 정보에 Electron이 표시될 수 있으며, 보안 정책에 따라 실행이 제한될 수 있습니다. 조직 관리 PC에서 차단되는 경우 해당 정책을 따라야 합니다.

## 사용 순서

1. 폴더 선택 → 원하는 저장소/이동식 디스크 폴더 선택.
2. 작업 날짜 선택 → 시작하기.
3. `선택한 저장소\YYYY-MM-DD` 폴더가 준비됩니다. 같은 이름의 기존 폴더는 재사용합니다.
4. 기본 카메라가 연결됩니다. 필요한 경우 장치 목록에서 카메라를 선택하거나 다시 연결을 누릅니다.
5. 주문번호 입력 → ● 또는 Enter로 녹화 시작.
6. Ⅱ 일시정지, ▶ 재개, ■ 정지 및 저장.
7. 오른쪽 위 ▱ 버튼: 실제 작은 윈도우로 전환하고 다른 창 위에 유지. □ 버튼: 큰 작업 화면으로 복귀.
8. 저장 폴더 열기로 결과 WebM 영상을 확인합니다.

화면의 크기 전환 버튼은 앱의 소형/큰 화면 전환입니다. Windows 제목 표시줄의 최소화/최대화/닫기 버튼도 사용할 수 있습니다. 녹화 중 닫기는 저장 보호를 위해 제한됩니다. 먼저 정지하여 저장을 완료하세요.

## 녹화 및 저장

- 카메라 실제 영상만 녹화하며, 카메라가 연결되지 않으면 녹화를 시작할 수 없습니다.
- 오디오는 녹음하지 않습니다. 해상도는 장치가 지원하는 범위에서 1280×720을 요청합니다.
- WebM(VP8), 요청 비트레이트 약 4 Mbps. 실제 파일 크기는 카메라/코덱에 따라 달라집니다.
- 파일명: `주문번호_시간_고유값.webm`. 같은 주문번호의 기존 영상을 덮어쓰지 않습니다.
- 약 1초 단위로 디스크에 순차 저장합니다. 저장 중에는 `.webm.partial`이며, 정상 정지 후 FFmpeg의 패킷 복사로 WebM의 길이·탐색 인덱스를 작성하고 `.webm`으로 저장합니다. 재인코딩이나 MP4 변환은 하지 않습니다.
- 저장소 분리, 디스크 용량 부족, 카메라 연결 종료 시 오류를 표시하거나 녹화를 정지합니다.
- 전원 차단·강제 종료 시 `.partial` 파일이 남을 수 있습니다. 해당 파일은 완전한 정상 영상이 아닐 수 있으며 자동 복구 기능은 없습니다.
- 카메라 한 대를 선택해 녹화하는 버전입니다. 여러 카메라 동시 녹화는 지원하지 않습니다.
- 기록 목록은 현재 앱 세션의 기록입니다. 파일 자체는 디스크에 남지만 앱 재실행 후 목록을 복원하지 않습니다.
- 로그인, 클라우드 업로드, 영상 발송, 압축 변환, 자동 업데이트는 없습니다.

## 카메라가 연결되지 않을 때

USB 연결, 다른 프로그램의 카메라 점유, Windows 카메라 개인정보 설정의 데스크톱 앱 접근 허용 여부를 확인하세요. 앱의 다시 연결 버튼으로 재시도할 수 있습니다.

## 소스 및 개발

실제 소스는 `resources/app/`에 있습니다. 개발용 Git 저장소는 이 폴더를 별도로 복사한 뒤 만들면 됩니다. 실행 배포물 전체를 Git에 올릴 필요는 없습니다.

- `main.js`: Windows 창, 네이티브 폴더 선택, IPC, 종료 보호.
- `preload.js`: 제한된 IPC 인터페이스.
- `storage.js`: 날짜 폴더와 영상 파일 순차 쓰기.
- `renderer.js`: 카메라, 녹화 상태, UI.
- `index.html`: 화면 및 스타일.
- `storage.test.js`: 저장 로직 검증.
- `renderer.test.js`: 녹화 흐름과 오류 처리 검증.

개발 환경에서만 Node.js/npm을 설치하여 다음 명령을 사용합니다. 최종 사용자에게는 필요 없습니다.

```
npm install
npm start
node --test storage.test.js renderer.test.js finalize-webm.test.js
```

Electron 버전: 45.1.0. 공식 Windows x64 배포본의 SHA-256을 대조한 뒤 소스를 포함했습니다. Electron 런타임 라이선스는 상위 폴더의 LICENSE 및 LICENSES.chromium.html에 있습니다.

## 검증 범위

JavaScript 구문, 날짜 폴더 재사용, 기존 파일 보존, 주문번호 경로 처리, 중복 녹화 방지, 영상 바이트 순차 저장, 중단 파일 유지, 빈 영상 처리 및 녹화 UI 상태 전이를 자동 검증했습니다.

이 패키지는 Linux 환경에서 Windows용 공식 런타임으로 조립했습니다. **실제 Windows에서 EXE 실행·USB 카메라·외장 저장소를 통한 종단 간 검증은 수행하지 못했습니다.** 처음에는 짧게 녹화하고 정지한 후 생성된 영상의 재생 여부를 확인하세요.

## v1.0.1 — 재생 위치 이동 수정

- 새로 녹화한 WebM에 Duration 및 Cues 탐색 정보를 기록합니다. 재생바 위치 선택 및 플레이어가 제공하는 앞뒤 이동 기능을 지원하도록 파일을 마무리합니다.
- 녹화 정지 후 `탐색 정보 정리 중` → `저장 완료` 순서입니다. 완료 전에는 앱을 종료하지 마세요.
- 영상 코덱·화질은 변경하지 않습니다. 디스크에서 한 번 읽고 다시 쓰므로 영상 크기만큼 임시 추가 공간과 후처리 시간이 필요합니다.
- 처리 실패 시 `.webm.partial` 원본을 보존하고 오류를 표시합니다.
- 기존에 녹화한 영상은 자동 수정되지 않습니다. 이 버전으로 새로 녹화한 영상을 확인하세요.
- FFmpeg는 resources/tools/ffmpeg.exe에 포함되어 있으며 설치나 인터넷 연결은 필요 없습니다. 라이선스 및 공급자 정보는 같은 폴더의 FFmpeg-LICENSE.txt 및 FFmpeg-README.txt를 확인하세요.
- 24초 테스트 영상에서 누락된 길이 정보를 보완하고, 20초→10초→3초 위치에서 프레임을 읽는 테스트와 압축 패킷 SHA-256 일치 검증을 통과했습니다. Windows 플레이어 및 USB 카메라 실환경 검증은 이 환경에서 수행하지 못했습니다.
- finalize-webm.test.js는 개발 환경의 ffmpeg/ffprobe 명령이 필요합니다. 사용자는 실행 파일에 포함된 도구를 사용하므로 별도 설치가 필요 없습니다.
